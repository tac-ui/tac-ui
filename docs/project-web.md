# project-web

## Goal

Ship the Tac UI design system as a React component library for web apps (Next.js first),
consuming tokens as CSS custom properties.

## Path

```
packages/web/
```

## Runtime and Language

React 18/19 (TypeScript strict), bundled by tsup to CJS + ESM with `.d.ts`.
Styling: Tailwind CSS 4 classes + class-variance-authority. Animation: Framer Motion.

## Consumers

- Product apps installing `@tac-ui/web`.
- `apps/docs` (dogfoods every component).

## In Scope

- Components: Accordion, Alert, AnimatedToggle/Toggle, Avatar, Badge, Banner, Breadcrumb,
  Button, Card, Chart, Checkbox, Chip, ClipboardText, CodeBlock, Collapsible, ColorPicker,
  Combobox, ConfirmDialog, CopyButton, DatePicker, Dialog, Divider, Drawer, Dropdown,
  EmptyState, Grid, Indicator, Input, Label, Layout, Link, Meter, Modal, MorphingCard,
  PageLayouts, Pagination, Popover, Progress, Radio, SegmentController, Select,
  SensitiveInput, Skeleton, Slider, Snackbar, Stack, StatusDot, Stepper, Switch, Table, Tabs,
  Textarea, Toast, Tooltip.
- `TacProvider` theme provider (optional `next-themes` integration).
- Accessibility hooks: `useFocusTrap`, `useFocusRestore`, `useRovingIndex`, `useReducedMotion`.
- Tailwind preset and theme plugin.

## Out of Scope

- Token values — owned by `@tac-ui/tokens`.
- Icon set — owned by `@tac-ui/icon` (re-exported at `@tac-ui/web/icons`).
- React Native — owned by `@tac-ui/native`.

## Architecture

```
packages/web/src/
├── components/<name>/     # one directory per component family (see AGENTS.md contract)
│   ├── <name>.tsx
│   ├── <name>.test.tsx    # optional
│   └── index.ts           # export * from './<name>';
├── constants/             # motion.ts (springs, easing, durations), styles.ts (focus ring…), types.ts
├── hooks/                 # use-accessibility, use-dropdown-position, use-reduced-motion, use-spotlight, use-tac-theme
├── provider/              # theme-provider.tsx (TacProvider)
├── tailwind/              # preset.ts (Tailwind preset + theme plugin)
├── utils/                 # cn.ts (clsx + tailwind-merge), merge-refs.ts
├── test/                  # repository guard tests (structure, colour literals, version)
├── icons.ts               # @tac-ui/web/icons entry
├── version.ts             # generated by scripts/sync-versions.mjs
└── index.ts               # public barrel
```

Components import shared code through `../../utils`, `../../hooks`, `../../constants`, and
other components through their directory index (`../button`).

## Interfaces

| Entry | Contents |
|-------|----------|
| `@tac-ui/web` | components, prop/variant types, `TacProvider`, hooks, motion constants, `cn`, `version` |
| `@tac-ui/web/icons` | re-export of `@tac-ui/icon` |
| `@tac-ui/web/tailwind` | Tailwind preset + theme plugin |

Stable DOM contract: components accept `className` and forward refs to their root element.

## Build and Test

```bash
pnpm --filter @tac-ui/web build       # tsup → dist/
pnpm --filter @tac-ui/web typecheck   # library + test tsconfig
pnpm --filter @tac-ui/web test        # vitest (node for guards, jsdom per-file for components)
```

Component tests opt into the DOM with `// @vitest-environment jsdom` and use
`@testing-library/react`. CI runs build, lint, typecheck and test on every PR.
