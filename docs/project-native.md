# project-native

## Goal

Ship the Tac UI design system as a React Native component library with API parity to
`@tac-ui/web`, consuming tokens through a theme context.

## Path

```
packages/native/
```

## Runtime and Language

React 19 + React Native ≥ 0.78 (TypeScript strict), bundled by tsup to CJS + ESM.
Animation: React Native `Animated`; `react-native-reanimated` and `react-native-svg` are
optional peers.

## Consumers

- Product apps installing `@tac-ui/native`.
- `apps/native-docs-app` (Expo showcase).

## In Scope

- Components: Accordion, Alert, AnimatedToggle/Toggle, Avatar, Badge, Breadcrumb, Button,
  Card, Checkbox, Chip, CodeBlock, ColorPicker, Combobox, DatePicker, Dialog, Divider,
  Dropdown, EmptyState, FloatingMenuBar, Indicator, Input, Progress, Radio,
  SegmentController, Select, Skeleton, Slider, Snackbar, Stack, Stepper, Switch, Table, Tabs,
  Textarea, Toast.
- `TacNativeProvider` + `useTacNativeTheme`.
- `createStyles` helper and motion spring configs.

## Out of Scope

- Web-only components (Chart, Drawer, Layout, Modal, Popover, Tooltip, …) unless a native
  equivalent is added deliberately; see `AGENTS.md` → Web / Native Parity.
- Navigation — consumers bring their own (React Navigation, Expo Router).

## Architecture

```
packages/native/src/
├── components/<name>/     # one directory per component family (see AGENTS.md contract)
│   ├── <name>.tsx
│   └── index.ts
├── constants/motion.ts    # tacSpring, springConfigs, duration
├── hooks/index.ts         # useTacNativeTheme re-export
├── provider/              # tac-native-provider.tsx
├── utils/                 # create-styles.ts
├── test/                  # repository guard tests
├── version.ts             # generated by scripts/sync-versions.mjs
└── index.ts               # public barrel
```

## Interfaces

| Entry | Contents |
|-------|----------|
| `@tac-ui/native` | components, prop types, `TacNativeProvider`, `useTacNativeTheme`, `createStyles`, motion constants, `version` |

## Build and Test

```bash
pnpm --filter @tac-ui/native build
pnpm --filter @tac-ui/native typecheck
pnpm --filter @tac-ui/native test     # vitest, node environment (guard tests)
```
